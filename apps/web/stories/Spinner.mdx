# Spinner usage

You can show Spinner while a request is pending and its amount of progress is unknown. A visible status label names the work, including when motion is reduced.

## Named work

You should avoid flashing a spinner for very brief work. For an initial list load, Skeleton better preserves the shape of the coming content; known progress belongs in Progress.

```html
<Spinner label="Saving your idea…" />
```

## Component contract

The optional `label` prop defaults to `Loading`. Spinner has no events or slots. Its ring uses the shared spin timing and stops under reduced motion; the label remains visible in a status region. The parent mounts and removes the spinner around the request.

# Select usage

Use Select for one choice from a fixed list. It uses a native select for keyboard and mobile interaction.

## Choose an option

Provide a visible label and unique option values. Include an empty-value option when a choice is required.

```html
<Select v-model="category" label="Category" :options="options" />
```

## Component contract

Required props are `label`, string `modelValue`, and `options`, an array of objects with `value`, `label`, and optional `disabled`. Optional props are `id`, `hint`, `error`, `required`, and `disabled`. Events are `update:modelValue(string)` and `blur(FocusEvent)`. Native attributes such as `name` reach the select. There are no slots. The parent owns validation and submission.

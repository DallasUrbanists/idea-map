# Principles

These principles guide Idea Map's interface. They are adapted from [Signal's principles](https://signal.chitransit.app/foundations/principles).

## Tokens hold every value

Use shared tokens for recurring visual decisions so changes can be made consistently across the interface.

## Storybook first, then the apps

Develop and review shared components and their important states in Storybook before using them in an app.

## The map is the canvas

Give the map room to remain useful while supporting content and controls fit around it. Provide a non-map way to reach information too.

## One of each

Favor one clear primary action per surface and consistent spacing, radii, and icons for the same role.

## Accessible by default

Use semantic controls, visible focus, descriptive labels, and touch-friendly targets. Communicate meaning with words and structure as well as color.

## Light and dark are equal

Design and check both themes, including text, boundaries, focus, and interactive states.

## Checked, not assumed

Test meaningful behavior and accessibility at the appropriate layer; review responsive layouts and real interactions.

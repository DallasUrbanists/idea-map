# Size and space

The scale follows [Signal's spacing and sizes](https://signal.chitransit.app/foundations/spacing). Use the corresponding `--step-*` tokens for new work.

## Spacing

The following reference maps Signal's spacing roles to the corresponding
Idea Map CSS tokens. The uses describe where the values can apply; existing
components do not all use these tokens yet. Values come from the shared token stylesheet.
Each sample bar uses the token as its width.

Existing components also use `--space-*` compatibility aliases; their suffixes are not pixel values.

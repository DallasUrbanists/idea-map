# Typography

Figtree is the typeface for headings, controls, and reading text. The variable
font ships with the web app and Storybook; the browser's sans-serif font is the
fallback. The ramp and examples follow
[Signal's typography reference](https://signal.chitransit.app/foundations/typography).

The sizes shown assume a 16 px root font size. On the web, the
relative sizes and browser zoom support text scaling; allow text to wrap and
controls to grow without hiding content.

Use tabular figures where numbers align in columns, such as times or counts.
Align table cells, column headings, and row headings to the left by default.

# Containers

Choose corners and shadows independently. Combine one `corner-*` class and one
`shadow-*` class, or use their CSS custom properties in a component's styles.
Neither class sets surface color, border, spacing, or stacking order.

## Corners

Corner tokens set shape without changing elevation. Samples use equal-size
shapes; a pill's visible curve is limited by the shape's dimensions.

## Shadows

Shadow tokens set elevation without changing corners. Grounded is the resting
choice for content in the page. Glow reuses the subtle control shadow. Apply Drag
only during a drag operation; Floating stays elevated while its surface is shown.
Shadows do not replace visible boundaries, selection marks, or keyboard focus.

For example, use `corner-card shadow-grounded` on a content card,
`corner-control shadow-glow` on a raised control, and
`corner-control shadow-floating` on a menu. Changing a shadow class leaves the
chosen corners intact.

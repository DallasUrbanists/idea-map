# Emojis

Use this reference to display emoji characters in text. For interface artwork, see <a href="./?path=/docs/components-icons--docs" target="_top">Icons</a>.

## Emoji usage

Use Fluent Emoji artwork for emoji characters, not as interface icons. Download
the selected SVG from the [Fluent Emoji collection](https://allsvgicons.com/pack/fluent-emoji/)
and include it with the application. For example, after saving the artwork as
`/emoji/house.svg`:

```html
<img class="emoji" src="/emoji/house.svg" alt="🏠">
```

```css
img.emoji {
  width: 1em;
  height: 1em;
  vertical-align: -0.1em;
}
```

The `1em` dimensions follow the font size of the text. Keep the original emoji
as the image's alternative text. Fluent Emoji is a collection of named artwork;
it does not itself replace emoji characters in user-generated text. Until an
accessible mapping and renderer are provided, leave those characters as text.
Fluent Emoji artwork is by Microsoft Corporation and is licensed under the MIT
license.

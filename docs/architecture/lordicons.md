# Lordicon attribution and reuse

Idea Map contributors can use this record to identify the source of the
Lordicon artwork, its attribution, and the conditions to review before sharing
it. The project's stated position is that Idea Map's use complies with
Lordicon's free license and Terms and Conditions.

## Artwork and attribution

[Lordicon](https://lordicon.com/) created the animated icons. Idea Map uses the
selected free icons from [collection 839425](https://lordicon.com/collections/839425)
as Lottie JSON files for interface artwork and demonstrates their animation
states in the Storybook **Components / Icons** page. The exports are stored in
the [web assets directory](../../apps/web/assets/lordicon-collection-839425/).
The separate `@lordicon/element` package provides the web player.

[Animated icons by Lordicon.com](https://lordicon.com/)

The project displays this attribution in its [README](../../README.md) and on
the Storybook Icons page. Lordicon's [attribution instructions](https://lordicon.com/docs/license/attribution)
also call for a website footer link when icons are used on every page.

## License and sharing

Lordicon's [license page](https://lordicon.com/licenses) describes the free
license as based on Attribution-NoDerivatives 4.0, with modifications including
commercial use and required attribution. The license page also requires
compliance with Lordicon's Terms and Conditions. The free license's
[usage summary](https://lordicon.com/docs/license/free) permits free icons in
applications and web design and lists restrictions on redistribution and icon
collections. Lordicon retains ownership of the artwork; the repository's
software license does not replace Lordicon's terms.

This compliance statement identifies the intended application use; it does not
identify separate permission to redistribute the standalone JSON files in a
public repository. Contributors should resolve that permission before
publishing the files, following the [reuse rights guide](../contributor-guides/reuse-rights-guide.md).

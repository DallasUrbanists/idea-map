# Agent guidance

This document is for AI agents and the people guiding them who want to find and
follow Idea Map's instructions before making changes. It points to the guidance
needed to work on the project and write useful documentation.

1. Read [CONTRIBUTING.md](CONTRIBUTING.md) and the task-oriented [agent guide](docs/agent-guidance.md) before changing this repository.
2. Follow more specific instructions in any affected directory.
3. Keep this file as the canonical entry point; harness adapters should link here rather than duplicate policy.
4. When creating or updating documentation, follow the mandatory [developer documentation rules](docs/agent-guidance.md#write-developer-documentation).
